# 统计口径与数据检查

本篇由原 `typhoon-error-report` 的参考文档迁入。统计定义必须与产生数据的代码、
实际表头和元数据一致；本 skill 只消费评测流水线写出的场次曲线与元数据，
字段以 `typhoon/tc*.csv` + `_meta.json` 的实际表头为准，配对统计以
[`typhoon_report.py`](../scripts/reporting/reports/typhoon_report.py) 为准。

## 当前项目与历史归档

当前确定性和集合场次曲线均包含 `track_err_km`、`at_km`、`ct_km`、
`wind_err_ms`、`pmin_err_hpa`。集合另有 `n_members`、`n_valid_members`
及 `track_err_km_a`、`at_km_a`、`ct_km_a`：

- 集合方案 B 主结果是 `track_err_km` / `at_km` / `ct_km`，相对实况检验集合平均位置。
- 方案 A 的 `*_a` 是成员误差平均，单列为附加指标，不混入方案 B。
- 集合 `wind_err_ms` / `pmin_err_hpa` 是成员有符号强度误差的平均，
  其绝对值可用于集合平均强度 MAE，不能称为成员 MAE。
- `n_valid_members` 是位置诊断有效成员数，不是风速/气压的通用分母。
- 当前 `_meta.json` 的 `aggregation` 同时描述 A/B，不是二选一开关。

历史 `_ensemble.csv` / `_members.csv` 及 `*_mean_*` 字段须另行映射；
不能要求当前产物有旧三件套，也不能沿用“集合汇总没有风速”的旧模板假设。
有效时间、种子 `seed` / `init_pos`、搜索框 `search` 和强度框均核实后描述，
不把默认参数当作实际参数。成员完成/失败记录不存在时写未知，不推断全部完成。

可执行入口要求每个场次具有 `_meta.json`，包含 `tcid`、`init_utc`、
`forecast_type`（det/ens，旧归档可显式声明）和 `tz_shift_h`。CSV 的 `valid_bjt` 使用 writer 的
无时区本地时间格式并逐行对齐。当前集合的 `aggregation.B` 必须明确包含
`track_err_km`；历史 `track_err_mean_km` 需 `aggregation="B"` 或
`aggregation.B` 明确该字段，不能靠文件名推定方案。
历史的完整文本声明“ensemble mean position error by lead_h (先平均位置再求误差, 方案B)”
也可识别。元数据陈旧或汇总没有时间/观测列时可用 `--verify-legacy-members`
逐行核验成员明细，报告保留原元数据和匹配算法；不以猜测或静默默认替代核验。
路径距离/强度单位与误差定义沿用当前 writer；其他来源需先人工核实并映射为
该契约，不能把未知单位/算法的数据直接当作同口径输入。

## 数据契约与字段映射

字段名是示例，不是自动适配保证。应根据表头、元数据和产生数据的代码建立映射。

| 概念 | 常见字段 | 单位/说明 |
|---|---|---|
| 时效 | `lead_h` | 小时 |
| 有效时间 | `valid_bjt` | 北京时间；必须核实，不凭名字推定 |
| 预测位置 | `fcst_lat`, `fcst_lon` | 度 |
| 观测位置 | `obs_lat`, `obs_lon` | 度 |
| 路径误差 | `track_err_km`, `track_err_mean_km` | km；后者也必须核实集合算法 |
| 沿路径误差 | `at_km`, `at_mean_km` | km，有符号 |
| 横路径误差 | `ct_km`, `ct_mean_km` | km，有符号 |
| 最低气压 | `fcst_pmin_hpa`, `obs_pmin_hpa` | hPa |
| 气压误差 | `pmin_err_hpa`, `pmin_err_mean_hpa` | hPa |
| 最大风速 | `fcst_vmax_ms`, `obs_vmax_ms` | m/s；核实平均时段与观测标准 |
| 风速误差 | `wind_err_ms` | m/s |
| 集合成员 | `member` | 成员标识；核实控制成员是否包含 |
| 集合规模 | `n_members`, `n_valid_members` | 计划/实际有效成员数；有效数可能按指标变化 |

典型起报文件名为 `tc<storm_id>_<YYYYMMDDHH>.csv`，但时间含义仍须检查元数据。例如 `init_utc`、`init_bjt` 和 `tz_shift_h=8` 可用于验证北京时与 UTC 的转换。必须验证：

`valid_time_utc = init_time_utc + lead_h`

文件名、元数据与有效时间冲突时，不自动选择其中一个继续。台风标识需包含足以区分年份和海盆的信息。若重复键完全相同，也只能按已声明规则去重并记录数量；重复键数值冲突必须解决后计算。

规范化坐标时说明经度约定，纬度限制为 [-90, 90]，经度转换前先核实源约定与有效范围。空字符串、NaN、正负无穷和已确认的缺测哨兵不能进入统计；不要把任意大误差当成缺测值删掉。报告各类排除计数。

## 误差公式

对同一指标、时效的配对样本集合 S，设有效有符号误差为 e：

- `ME = sum(e) / N`
- `MAE = sum(abs(e)) / N`
- 默认强度误差 `e = forecast - observation`，但必须核实已有数据的符号，不能直接覆盖历史定义。
- 路径距离非负，其均值本身就是平均路径误差，不另取绝对值。

使用大圆距离时，以弧度计算 Haversine：

```text
a = sin²((lat_f - lat_o)/2)
    + cos(lat_f) * cos(lat_o) * sin²((lon_f - lon_o)/2)
d = 2 * R * asin(sqrt(clamp(a, 0, 1)))
R = 6371.0 km
```

如果项目已有其他球面半径或椭球算法，应保持一致并记录；不同算法的结果不能未经解释混用。

AT/CT 依赖观测轨迹的参考方向、切向量和投影算法。优先使用来源明确的字段，记录正负方向及端点/静止位置处理方式。不能未经核实将 CT 正负解释为东/西，将 AT 正负解释为快/慢。需要重算但参考轨迹或定义缺失时，询问用户。

## 集合定义

对某个起报个例和时效，成员位置为 P_m，观测为 O：

- 集合平均位置误差：`d(mean_position(P_m), O)`。
- 成员平均路径误差：`mean(d(P_m, O))`。

二者通常不相等。某些数据使用 B 列 `track_err_km` 表示前者，A 列 `track_err_km_a` 表示后者；只能经元数据确认后映射。

同样，集合平均强度误差的绝对值 `abs(mean(f_m) - o)` 不等于 `mean(abs(f_m - o))`。AT/CT 是对平均位置重新计算还是成员有符号投影平均，也必须明确，不能仅凭 `*_mean_*` 字段名判断。

成员必须先在同一有效时间上对齐，并使用有效的纬经度成对记录。各指标记录实际有效成员数，不能让缺失成员作为零参与均值。观测应在同个例同有效时间上一致。

跨日界线时不能简单平均原始经度。新计算可采用明确记录的球面单位向量平均；平均向量接近零时没有稳定均值位置，应报缺测或停止。已有数据若使用其他位置平均算法，先核实并保持一致；发现日界线问题时报告影响，在用户确认统一算法后重算所有比较模型，不能只修一个模型。

默认每个起报个例在某时效贡献一个集合指标，之后个例等权。不能因某模型有 51 个成员、另一模型有 11 个成员，就给前者更大权重。应披露规模差异，必要时单列同成员数敏感性分析。

## 严格配对与权重

令键 `K = (storm_id, init_time_utc, lead_h)`。

1. 可先取各模型起报个例的交集并报告覆盖率。
2. 对每个指标和时效，再取各模型该指标均有效的 K 交集。
3. 以这批键计算所有模型值和差值。

文件交集不等于有效记录交集。台风数不等于起报个例数；一个台风多次起报具有相关性。

默认逐时效个例等权。若需要台风等权，先台风内求均值再跨台风求均值，并明确这是不同估计量。若需要跨时效总分，先约定是每条记录等权、每个时效等权，还是固定完整个例等权，不能直接平均表中所有数值。

模型比较差值建议 `delta = model_A - model_B`；对路径误差与 MAE，负值表示 A 较小。ME 的数值较小不等于偏差较小，应结合距零的大小和方向解释。

## 不确定性与敏感性

台风分组 bootstrap：

1. 从实际纳入的台风列表中有放回抽取同样数量的台风。
2. 保留每次抽中台风的全部起报记录；重复抽中须重复计入，不能被字典去重。
3. 每次重算相同权重定义的统计量；比较模型时所有模型共享抽样，差值保持配对。
4. 建议 2,000 次、固定随机种子，以第 2.5/97.5 百分位报告 95% 区间。

点估计仍是原样本的个例等权均值；分组重采样不意味着改用台风等权。记录实际次数、种子、区间方法和无法计算的重采样次数。台风组过少时区间不稳定；仅一个台风时不能宣称估计了台风间不确定性。

少样本阈值、主要时效窗口应事先声明，不能按结果优劣挑选。可用固定时效窗口中所有指标、模型均完整的个例重新比较，检查随时效变化的样本组成影响；示例窗口 24–120 h，但不是所有项目的强制范围。

曲线变平或长时效误差下降可能是剩余样本改变，不能直接解释为技巧改善。未经检验不使用“显著优于”；检验多个模型/指标/时效时说明多重比较限制。
