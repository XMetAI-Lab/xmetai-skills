# 变量约定：模板生成，按来源核对

从 [Profile 模板与候选值](./profile-templates.md) 选择字段结构并生成任务配置。
模板注释中的变量、气压层、时次等是带日期的示例候选，不是权威变量注册表。

以下路径相对 Datakit 仓库根：

| 问题 | 先查哪里 |
|---|---|
| 本次下载什么外部变量、层次、时次、范围 | 用户任务 Profile |
| 字段结构和仓库示例候选 | skill 自带 Profile 模板；下载器 `profiles/*.yaml` 仅作参考 |
| 字段是否受支持、变量是否可用 | 当前下载器规则及对应官方数据集定义 |
| 本次实际启用哪些 Profile | 用户的 Batch YAML |
| 通用变量短名和分组 | `datakit/schema/variables.py` |
| 通道元数据和预处理声明 | `datakit/schema/channel_attributes.py` |
| 标准产品的完整通道、顺序及变体 | `datakit/schema/dataset_products.py` 和对应产品模块 |
| 时间语义 | `datakit/schema/semantics.py` |

## 使用原则

1. 从用户的物理含义出发，核对外部变量名及层次，再检查与目标产品的对应关系。
2. Profile、源文件变量名和标准产品通道名不必相同；不能只按字符串相似度认定等价。
3. 并非所有标准通道都可直接下载；派生风速、单位缩放、辐射换算、降水变换等可能
   属于后续构建。明确区分“下载原值”和“加工后的标准通道”。
4. 下载 Profile 与 schema 尚不保证自动同步；发现缺项或冲突就说明，提出具体
   待确认映射，不擅自改变共享定义。
5. 区分瞬时量、区间累计、区间平均和日统计；不把六小时抽样称为六小时平均。
6. 用户只要求下载时，不自动执行转换、归一化、插值或标准数据集校验。
