# Usage

Use for LazyConfig, Zarr/NetCDF/static data, model code, training/eval, ONNX/deploy, or tensor-shape debugging.

Flow:

1. Inspect repo rules and local changes.
2. Pick the relevant `SKILL.md` reference.
3. Prefer read-only scripts and dry runs.
4. Ask before Zarr mutation.
5. Report only validation that actually ran.
